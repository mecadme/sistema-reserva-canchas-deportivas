# Infraestructura local

Este directorio contendrá Docker Compose, configuración de contenedores y archivos auxiliares para levantar el sistema completo en un entorno local.

La composición deberá incluir, como mínimo:

- PostgreSQL y las bases o esquemas definidos por servicio.
- Los microservicios habilitados para la entrega.
- El `shell` y los microfrontends remotos.
- Variables de ejemplo sin credenciales reales.

Kubernetes no forma parte del alcance.
