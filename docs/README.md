# Documentación

Este directorio concentra los entregables y decisiones compartidas del proyecto.

- `requirements/`: documento de alcance funcional y técnico recibido.
- `architecture/`: diagramas, modelo de datos y decisiones de arquitectura.
- `TEAM.md`: propuesta de responsabilidades para los cuatro integrantes.
- `ROADMAP.md`: secuencia inicial de trabajo.

Las decisiones importantes deben registrarse antes de que distintos componentes dependan de ellas. Como mínimo: stack frontend, versiones backend, autenticación, contratos REST, propiedad de datos, puertos y estrategia de despliegue local.
