# Documentación

Este directorio concentra el alcance, la arquitectura, las responsabilidades y el estado del proyecto.

- `requirements/`: documento de alcance funcional y técnico recibido.
- `architecture/`: arquitectura implementada, integraciones, decisiones y modelos de datos.
- `TEAM.md`: responsables de frontend y backend.
- `ROADMAP.md`: estado actualizado de las fases y trabajo pendiente.

La documentación complementaria se encuentra junto al componente correspondiente:

- `../frontend/README.md`: microfrontends, Module Federation y ejecución local.
- `../backend/README.md`: microservicios, seguridad, Swagger y pruebas.
- `../database/README.md`: migraciones, seeds e independencia de datos.
- `../infra/README.md`: despliegue local integrado con Docker Compose.

## Estado documental

La arquitectura y las instrucciones técnicas reflejan el sistema integrado actual. El sistema ha sido levantado y probado funcionalmente; las pruebas automatizadas end-to-end permanecen pendientes y se abordarán en una fase posterior.

Las decisiones importantes deben mantenerse sincronizadas entre este directorio y los README de cada componente.
