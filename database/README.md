# Base de datos

Aquí se organizarán las migraciones, DDL y datos de prueba de PostgreSQL por microservicio.

```text
database/
├── usuarios/
├── canchas/
└── reservas/
```

Cada servicio debe administrar sus propias migraciones. Los scripts compartidos de este directorio se reservan para inicialización local, demostraciones y entregables académicos.
